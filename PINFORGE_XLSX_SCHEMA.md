# PinForge → Publisher schema

Minimum columns: `pinterest_account_id`, `publish_date`, `title`, `image_url`.

Recommended: `description`, `destination_url`, `board_id`, `board`, `section_id`, `section`, `alt_text`.

`pinterest_account_id` is a stable internal ID such as `pinterest_01`. It is not the Pinterest user ID and never contains OAuth credentials.
